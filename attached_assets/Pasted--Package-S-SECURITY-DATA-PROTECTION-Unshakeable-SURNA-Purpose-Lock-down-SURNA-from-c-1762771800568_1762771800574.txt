

🛡️ Package S — SECURITY & DATA PROTECTION (Unshakeable SURNA)

🎯 Purpose

Lock down SURNA from code to cloud: auth, sessions, APIs, uploads, payments, data at rest, admin, CI/CD, backups, monitoring, and incident response — with zero redesign and no schema duplication.


---

🧩 Developer Sayings / Hard Rules

> Do not add new colors or UI; this is backend/middleware/config plus tiny client guards.

Least privilege everywhere: users, services, DB roles, API keys, admin.

Zero trust: validate every input, authenticate every request, authorize every action.

Never store secrets in code, logs, or client bundles.

Defense in depth: even if one layer fails, others still block.

Auditable: every sensitive action is logged with who/when/what (no PII in logs).

Fail closed: unknown states default to deny.

1) 🔐 Authentication & Session Hardening

Sayings

Use OIDC/JWT for clients; short-lived access tokens (5–10 min) + rotating refresh tokens (7–30 days).

Store refresh token in httpOnly, Secure, SameSite=Strict cookie.

Rotate & revoke refresh tokens (track jti in Redis).

Re-auth before sensitive actions (payouts, email change).

Enforce MFA/WebAuthn for Admin + optional for users.


Code (Express, TS)

// server/security/auth.ts
import jwt from "jsonwebtoken";
import { randomUUID } from "crypto";
import { redis } from "../cache/redisWrapper";

const ACCESS_TTL = "10m";       // short
const REFRESH_TTL_SEC = 60*60*24*14; // 14 days

export function signAccess(user: { id:string; role:string }) {
  return jwt.sign({ sub:user.id, role:user.role }, process.env.JWT_ACCESS_SECRET!, { expiresIn: ACCESS_TTL });
}
export async function signRefresh(userId:string) {
  const jti = randomUUID();
  const token = jwt.sign({ sub:userId, jti }, process.env.JWT_REFRESH_SECRET!, { expiresIn: REFRESH_TTL_SEC });
  await redis.set(`rt:${jti}`, userId, { EX: REFRESH_TTL_SEC });
  return token;
}
export async function rotateRefresh(oldJti:string, userId:string) {
  await redis.del(`rt:${oldJti}`); // revoke old
  return signRefresh(userId);
}
export async function isRefreshValid(jti:string) {
  return Boolean(await redis.get(`rt:${jti}`));
}

Route guards

// middleware example
export function requireAuth(req,res,next){
  const hdr = req.headers.authorization || "";
  const token = hdr.startsWith("Bearer ") ? hdr.slice(7) : null;
  try {
    const payload = jwt.verify(token!, process.env.JWT_ACCESS_SECRET!);
    (req as any).user = payload;
    return next();
  } catch {
    return res.status(401).json({ error:"unauthorized" });
  }
}

2) 🔏 Authorization (RBAC & Resource Scopes)

One RBAC matrix; assign roles (user, captain, coach, shop_owner, finance_admin, moderator, super_admin).

Route-level and resource-level checks: can this user modify this team/event/shop?


// server/security/rbac.ts
export const PERMS = {
  "user:read": ["user","captain","coach","moderator","super_admin"],
  "team:manage": ["captain","moderator","super_admin"],
  "payments:payout": ["finance_admin","super_admin"],
  "admin:*": ["super_admin"]
} as const;

export function requirePerm(perm:keyof typeof PERMS){
  return (req,res,next)=>{
    const role = (req as any).user?.role;
    if (!role || !PERMS[perm].includes(role)) return res.status(403).json({error:"forbidden"});
    next();
  }
}

3) 🧼 Input Validation & Output Encoding

Zod on every request body/query/params.

Reject on first error; never coerce silently.

HTML escape untrusted text before rendering; allow minimal markdown if needed.


// server/security/validator.ts
import { z } from "zod";
export const createEventSchema = z.object({
  title: z.string().min(3).max(120),
  description: z.string().max(5000),
  timeStart: z.string().datetime(),
  location: z.object({ lat:z.number(), lng:z.number(), address:z.string().max(200).optional() })
});
export const validate = (schema: z.ZodSchema) => (req,res,next)=>{
  const r = schema.safeParse({ ...req.body, ...req.query, ...req.params });
  if (!r.success) return res.status(400).json({ error:"bad_request", details: r.error.flatten() });
  (req as any).data = r.data; next();
};

5) 🚧 Rate Limiting, Abuse & Bot Control

Per IP, per user, per route with Redis counters.

Add Proof-of-Work / CAPTCHA only on attack spikes (toggle).


// server/security/rateLimit.ts
import { RateLimiterRedis } from "rate-limiter-flexible";
import { redisClient } from "../cache/redisWrapper";
export const authLimiter = new RateLimiterRedis({ storeClient: redisClient, keyPrefix:'rl:auth', points:10, duration:60 });
export function rateLimit(limiter: RateLimiterRedis){
  return async (req,res,next)=>{
    try { await limiter.consume(req.ip!); next(); }
    catch { res.status(429).json({error:"too_many_requests"}); }
  }
}

// server/security/uploads.ts
import fileUpload from "express-fileupload";
export const uploadsMw = fileUpload({ limits: { fileSize: 100 * 1024 * 1024 } }); // 100MB
export function enforceMime(allowed:string[]) {
  return (req,res,next)=>{
    const f = (req as any).files?.file; if (!f) return res.status(400).json({error:"missing_file"});
    if (!allowed.includes(f.mimetype)) return res.status(415).json({error:"unsupported_media_type"});
    next();
  };
}

9) 🧊 Encryption (At Rest + In App)

TLS everywhere (Nginx terminates).

DB at rest: enable volume encryption on the host/cloud.

Field-level encryption for sensitive PII (email, phone) and tokenize where possible.


// server/security/encryption.ts
import sodium from "libsodium-wrappers";
let key:Uint8Array;
export async function initCrypto(){
  await sodium.ready;
  key = sodium.from_hex(process.env.FIELD_ENC_KEY_HEX!); // 32 bytes
}
export function enc(plain:string){
  const nonce = sodium.randombytes_buf(sodium.crypto_secretbox_NONCEBYTES);
  const ct = sodium.crypto_secretbox_easy(sodium.from_string(plain), nonce, key);
  return Buffer.concat([Buffer.from(nonce), Buffer.from(ct)]).toString("base64");
}
export function dec(b64:string){
  const buf = Buffer.from(b64,"base64");
  const nonce = buf.subarray(0,24);
  const ct = buf.subarray(24);
  const pt = sodium.crypto_secretbox_open_easy(ct, nonce, key);
  return sodium.to_string(pt);
}

Use in Drizzle select/insert mappers for fields like email_enc.
