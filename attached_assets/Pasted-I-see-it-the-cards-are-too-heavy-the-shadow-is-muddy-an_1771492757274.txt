I see it — the cards are too heavy, the shadow is muddy, and that green in the nav icons clashes with everything. Let me fix this.

---

The Problems

Issue	Why It Hurts	
Dark shadow on gradient	Looks dirty, not premium	
Red → black gradient	Too dramatic, feels aggressive	
Green active icon	Doesn't match the coral/blue sport colors	
No consistency	Each card fights for attention	

---

The Fix: Clean, No Shadow, Sport Color Only

New Card Style

```
┌─────────────────────────┐
│  [Coral sport color]    │ ← solid, no gradient
│  🥊 BOXING               │
│                         │
│  NYC Fight Academy      │
│  12 / 25 members        │
│                         │
│  [Join Team]            │
└─────────────────────────┘
```

No shadow. No black fade. Just clean color.

---

CSS Fix for Cards

```css
.team-card {
  /* Remove gradient, use solid sport color */
  background: var(--sport-color); /* #FF6B4B for boxing */
  
  /* Remove shadow */
  box-shadow: none;
  
  /* Subtle border for definition */
  border: 1px solid rgba(255, 255, 255, 0.1);
  
  border-radius: 20px;
  padding: 20px;
  
  /* Or if you want VERY subtle lift */
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.08); /* Almost invisible */
}
```
