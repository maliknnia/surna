Sports Hub — Product & Tech Spec

Goal

When the user taps Sports, they land on a Sports Hub that surfaces all sports features at a glance:

Find, Coaches, Teams, Events, Book Fields, Challenges, Leaderboard, Nearby (Map).
From here, each tile routes to its sub-page. Back from any sub-page returns to the Sports Hub, not Home.


UX Rules

Header: “Sports” + small subtitle “Find, book, join, play.”

2-column tile grid (compact, touch-safe 44px min).

Remember last visited sub-tab (optional nice-to-have).

Fast, no blank flashes: prefetch the first 6 tiles’ data on idle.

4) SportsLayout (optional sticky tabs for quick switching)

// SportsLayout.tsx
import { NavLink, Outlet } from "react-router-dom";

const tabs = [
  { to: "/sports/find", label: "Find" },
  { to: "/sports/coaches", label: "Coaches" },
  { to: "/sports/teams", label: "Teams" },
  { to: "/sports/events", label: "Events" },
  { to: "/sports/book", label: "Book" },
  { to: "/sports/challenges", label: "Challenges" },
];

export default function SportsLayout() {
  return (
    <div className="min-h-screen bg-gray-50">
      <div className="sticky top-0 z-10 bg-white/80 backdrop-blur border-b">
        <div className="mx-auto max-w-4xl px-4 py-2 flex gap-2 overflow-x-auto">
          {tabs.map(t => (
            <NavLink
              key={t.to}
              to={t.to}
              className={({isActive}) =>
                `px-3 py-1.5 rounded-full text-sm ${isActive ? 'bg-black text-white' : 'bg-gray-100 text-gray-700'}`
              }
            >
              {t.label}
            </NavLink>
          ))}
        </div>
      </div>
      <div className="mx-auto max-w-4xl px-4">
        <Outlet />
      </div>
    </div>
  );
}

Data/Performance

Prefetch minimal data for: coaches, events, nearby on idle (React Query prefetch).

Cache last tab in localStorage (web) or AsyncStorage (RN) as sports:lastTab.

Back stack: From any /sports/* route, Back returns to /sports (use nested routes / stacks).

No blocking spinners: Show skeleton cards for sub-pages.
