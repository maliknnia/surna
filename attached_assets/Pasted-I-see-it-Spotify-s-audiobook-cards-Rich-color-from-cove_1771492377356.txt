Concept: "Venue Cards" for Places/Gyms

Like Spotify audiobooks — color extracted from venue photo, full-bleed card, immersive.

```
┌─────────────────────────┐
│  [Gym photo - full]     │
│  ┌─────────────────┐    │
│  │ Gold's Gym      │    │
│  │ ⭐ 4.8 • 2mi    │    │
│  │                 │    │
│  │ [Preview] [+]   │    │
│  └─────────────────┘    │
│  ↑ gradient from photo  │
└─────────────────────────┘
```

---

Structure

Element	Style	
Background	Color extracted from venue photo	
Image	Left side, square, rounded	
Title	Bold, white	
Meta	Rating, distance, sport tags	
Actions	"Preview" (tour), "+" (save)	
Gradient	Photo color → dark
