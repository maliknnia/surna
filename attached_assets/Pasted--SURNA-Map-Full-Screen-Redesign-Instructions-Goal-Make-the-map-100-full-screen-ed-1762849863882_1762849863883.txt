🗺️ SURNA Map — Full-Screen Redesign Instructions

🎯 Goal

Make the map 100% full screen — edge-to-edge, no borders or empty padding — like Snapchat Map or Google Maps mobile mode.
Keep only the top bar (Places / Teams / Map / Coaches / Events / Sports) and overlay icons (filter, location, etc.) floating on top.


---

🧩 Developer Sayings

> Remove all container padding or margins around the <MapContainer>.

The map must fill all available viewport height (100vh) and width (100vw) starting below the top navigation bar.

No card, no border, no box shadow.

Overlay buttons (Filter, GPS, etc.) must float on the map with transparent background and soft shadows.

Use position: absolute to layer controls, not inside a separate div.

Make it responsive — both portrait and landscape view.





---

⚙️ Code Example

// src/pages/Sports/Map.tsx
import { MapContainer, TileLayer } from 'react-leaflet';
import 'leaflet/dist/leaflet.css';
import './MapPage.css';

export default function MapPage() {
  return (
    <div className="map-wrapper">
      <MapContainer
        center={[51.505, -0.09]}
        zoom={10}
        zoomControl={false}
        scrollWheelZoom={true}
        className="surna-map"
      >
        <TileLayer
          attribution='&copy; OpenStreetMap'
          url="https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png"
        />
        {/* Add pins, layers, events here */}
      </MapContainer>

      {/* Floating Controls */}
      <div className="map-control filter">
        <i className="icon-filter" />
      </div>
      <div className="map-control gps">
        <i className="icon-location" />
      </div>
    </div>
  );
}
