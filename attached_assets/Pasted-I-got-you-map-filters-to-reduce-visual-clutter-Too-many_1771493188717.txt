Traffic Reduction: Clustering

```javascript
// When zoomed out, cluster pins
map.addLayer({
  id: 'clusters',
  type: 'circle',
  filter: ['has', 'point_count'],
  paint: {
    'circle-color': [
      'step',
      ['get', 'point_count'],
      '#51bbd6',  // Small cluster
      100,
      '#f1f075',  // Medium
      750,
      '#f28cb1'   // Large
    ],
    'circle-radius': [
      'step',
      ['get', 'point_count'],
      20,
      100, 30,
      750, 40
    ]
  }
});
```

Zoom in → clusters split into individual pins
